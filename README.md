## LocalHub 是什么

LocalHub 是一个完全本地运行的媒体浏览器和整理工具。

把 `LocalHub.exe` 放进媒体总目录，双击后，它会在浏览器里把普通文件夹变成一个真正可用的私人媒体站：视频可以直接播放，图片目录会自动变成图包，Tag 和评分可以随手修改，文件可以在浏览过程中改名、拖动分类，而不需要在网页和资源管理器之间来回切换。

```text
媒体库/
├─ LocalHub.exe
├─ video-a.mp4
├─ 电影/
│  ├─ movie-01.mp4
│  └─ movie-02.mp4
├─ 系列/
│  └─ episode-01.mkv
└─ 图包/
   ├─ 001.jpg
   ├─ 002.jpg
   └─ 003.jpg
```

> LocalHub 默认只监听 `127.0.0.1`。媒体不会上传到互联网。

## 30 秒开始使用

1. 从 [Releases](../../releases/latest) 下载 `LocalHub.exe`。
2. 把 EXE 放到你的媒体总目录。
3. 双击运行。

程序没有 CMD 黑框，会自动打开浏览器，并在 Windows 托盘保留 LocalHub 图标。

托盘菜单可以：

- 打开 LocalHub
- 打开媒体文件夹
- 退出 LocalHub

普通用户不需要安装 Python、Node.js 或 FFmpeg。

## 像视频网站，但更适合本地媒体

| 浏览 | 播放 | 整理 |
|---|---|---|
| 首页只保留约 13–15 个视频 | 自定义播放时间轴 | Tag 原地增删 |
| 全部视频独立分页 | 自动兼容播放 | 1–5 分个人评分 |
| 文件夹导航 | 继续观看 | 双击标题改名 |
| 图包 / 图册 | 倍速、音量、全屏 | 拖动到文件夹分类 |
| 文件名 / 文件夹 / Tag 搜索 | AVI / MPG / TS 等兼容处理 | 收藏与进度自动迁移 |

### 首页不会变成“几千项媒体墙”

LocalHub 不会把整个媒体库一次性塞进首页。

- 优先展示根目录视频。
- 首页最多约 15 个视频。
- 根目录视频不够时，从不同文件夹抽取内容补足。
- “全部视频 / 文件夹 / 搜索”使用真正分页，每页约 30 项。

即使媒体库有几千个文件，浏览器也只处理当前需要的那一小部分。

## 图包 / 看书模式

一个文件夹里有多张图片时，LocalHub 会把它理解成一个图包或一本书，而不是把几百张图片全部铺到媒体墙。

```text
某个文件夹/
├─ video.mp4
├─ 001.jpg
├─ 002.jpg
└─ 003.jpg
```

在 LocalHub 里会变成：

```text
video.mp4
图包 · 3 张图片
```

打开图包后才读取原图。

- 普通横图 / 竖图按原始比例完整显示。
- 超长漫画页自动按宽度阅读，并在阅读区域内纵向滚动。
- 切页时只保留当前页和少量预加载图片。

## 视频预览：低 I/O，不拿原视频做媒体墙

LocalHub 的视频卡片不会创建一堆 `<video>` 元素。

缩略图按需获取：

1. 优先尝试 Windows Shell / Explorer 的共享缩略图能力。
2. 未命中时使用本地 FFmpeg 快速 seek 抽一帧。
3. 前端只请求当前视口和下一排需要的预览。

鼠标稳定停留在一个视频上时，会渐进获取最多 6 个低清视频帧做预览；全局只允许一个视频执行这项工作。

鼠标快速扫过媒体墙不会触发几十个视频同时解码。

## 播放器兼容层

浏览器对 MP4 / MOV / AVI / MPG / TS / MKV 的支持取决于内部编码，所以 LocalHub 不只看扩展名。

打开视频时会按需判断媒体信息：

```text
适合浏览器原生播放
→ 直接播放

编码可用但容器不友好
→ 本地无损 remux

编码本身不适合浏览器
→ 本地兼容转成 H.264 / AAC
```

原文件不会被转换或覆盖。

兼容播放产生的临时文件放在 `.localhub/compat/`，由 LocalHub 清理。

## 整理功能不会打断观看

### Tag

视频卡片和播放页都固定有一条轻量 Tag 区域：

```text
#剧情  #人物  #4K  +                  ★ 4
```

点击 `+` 会直接在这一行出现输入框。

- Enter：新增 Tag
- 不会覆盖已有 Tag
- 单个 Tag 可直接删除
- 点击 Tag 可用于筛选

Tag 保存到 `.localhub/metadata.json`，不会写进视频文件。

### 评分

每个视频支持 `1–5` 分个人评分。

评分只是为了让你自己快速判断内容质量，所以显示很克制，不做成抢眼的大评分卡。

### 改名

播放页面直接双击标题即可改名：

```text
old-name.mp4
↓ 双击
[new-name] .mp4
```

- 扩展名自动保留
- Enter 保存
- Esc 取消
- 改名后回到当前视频
- 尽量恢复之前的播放位置

### 移动 = 分类

“移动”不再要求输入路径。

进入 **移动位置** 模式后，可以直接把视频卡片拖到左侧文件夹：

```text
视频卡片
   ↓ 拖动
左侧目标文件夹
   ↓ 松开
完成分类
```

也可以先点视频，再点目标文件夹完成一键移动。

移动或改名以后，Tag、评分、收藏和观看进度会跟着新路径迁移。

## 为什么在大媒体库里仍然轻

LocalHub 2 的原则是：**索引元数据，不预加载内容。**

第一次运行会扫描媒体目录并建立轻量目录索引：

```text
.localhub/
├─ metadata.json       # Tag / 评分等本地元数据
├─ catalog-v2.json     # 轻量目录索引快照
├─ compat/             # 兼容播放临时文件
├─ runtime.json        # 当前运行实例，退出后移除
├─ startup-error.log   # 仅启动失败时生成
└─ server-error.log    # 仅服务器请求异常时生成
```

索引只记录：

- 文件名
- 相对路径
- 类型
- 大小
- 修改时间
- Tag / 评分等少量元数据

不会把视频或图片内容写进索引。

第二次启动可以先使用上次的索引快照显示首页，再后台刷新真实目录。

## 支持格式

**图片**

`jpg` `jpeg` `png` `webp` `gif` `avif` `bmp` `svg`

**视频**

`mp4` `webm` `m4v` `mov` `mkv` `avi` `ogv` `mpeg` `mpg` `ts`

能否直接原生播放取决于视频 / 音频编码；LocalHub 会在需要时尝试兼容播放。

## 隐私与文件安全

LocalHub 是 local-first 工具：

- 默认绑定 `127.0.0.1`
- 不需要账号
- 不需要远程服务器
- 不上传媒体
- Tag / 评分保存在本地
- 搜索在本地索引完成

需要注意：**改名和移动是真实文件操作。**

LocalHub 会阻止覆盖同名文件，并保留扩展名，但仍应像使用文件管理器一样对待这些操作。

## 开发与构建

普通用户只需要 Release 中的 `LocalHub.exe`。

源码构建：

```powershell
.\build_windows.ps1
```

GitHub Actions 会执行：

1. Python 语法检查
2. JavaScript 语法检查
3. 启动器 smoke test
4. 目录 / 首页 / 图包 smoke test
5. 缩略图与 6 帧预览测试
6. 媒体兼容播放测试
7. Tag / 评分 / 改名元数据测试
8. PyInstaller 单 EXE 构建
9. 在故意损坏的代理环境下执行打包 EXE 自检
10. 生成 SHA256
11. 正式 release 提交自动发布 GitHub Release
