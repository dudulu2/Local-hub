# LocalHub

一个完全本地运行的媒体浏览器，把普通文件夹变成类似视频网站的图片 / 视频媒体库，并在不打断观看体验的前提下提供轻量媒体整理能力。

## 特点

- 自动递归扫描当前目录及子目录中的视频和图片
- 深色高对比媒体网站式布局
- 视频 / 图片 / 收藏 / 继续观看分类
- 文件夹导航与 Tag 导航
- 文件名、目录、Tag 联合搜索
- 名称、时间、文件大小排序
- 视频大窗播放、拖动进度、全屏、倍速等浏览器原生控制
- HTTP Range 分段读取，大视频无需一次性载入内存
- 图片大图查看
- 上一个 / 下一个与键盘方向键切换
- 收藏状态保存到浏览器本地存储
- 自动记忆视频播放位置并显示继续观看
- 视频卡片视口懒加载，避免大型媒体库同时读取大量视频
- 响应式桌面 / 窄屏布局
- 不上传媒体，默认仅监听 `127.0.0.1`
- 后端只有 Python 标准库，无 pip 依赖

## 整理功能

LocalHub 的整理功能默认隐藏，不会把正常浏览页做成文件管理器。

### 单个媒体

正常点击媒体仍然直接观看。需要整理时可以：

- 点击媒体卡片右上角 `⋯`
- 在播放器中点击 **整理**
- 播放器打开时按 `E`

整理面板会停靠在播放器右侧，而不是盖住视频。可执行：

- 添加、删除 Tag
- 从已有 Tag 中快速选择
- 修改文件名
- 移动到已有文件夹
- 输入新文件夹路径并自动创建后移动

改名时扩展名自动保留，减少误改视频格式的风险。移动和改名完成后，LocalHub 会迁移该文件的收藏和播放进度记录。

### 批量整理

点击页面顶部 **整理** 后才进入批量模式。此时媒体卡片显示选择状态，底部出现批量工具条，可：

- 全选当前筛选结果
- 给多个媒体批量添加 Tag
- 批量移动到指定目录
- 随时退出整理并恢复普通视频网站浏览状态

批量移动会先检查目标目录是否存在同名文件，发现冲突时会阻止操作，避免静默覆盖。

## Tag 数据存储

Tag 不写入视频或图片文件本身。第一次保存 Tag 后，媒体根目录会自动生成：

```text
.localhub/
└─ metadata.json
```

`.localhub` 是 LocalHub 自己的隐藏数据目录，扫描媒体时会自动忽略。改名或移动媒体时，对应 Tag 会一起迁移。

## Windows 最简单用法

1. 下载本仓库全部文件。
2. 把这些文件放进你要浏览的视频 / 图片总文件夹。
3. 双击 `打开媒体库.bat`。
4. 浏览器会自动打开 LocalHub。

项目会递归扫描同文件夹下的媒体，因此也支持：

```text
媒体库/
├─ 打开媒体库.bat
├─ server.py
├─ index.html
├─ styles.css
├─ app.js
├─ 视频/
│  ├─ A.mp4
│  └─ B.webm
└─ 图片/
   ├─ 1.jpg
   └─ 2.png
```

## 命令行运行

```bash
python server.py
```

指定其他媒体目录：

```bash
python server.py --root "D:\Videos"
```

不自动打开浏览器：

```bash
python server.py --no-open
```

默认地址通常为：

```text
http://127.0.0.1:8787/
```

若 8787 已占用，会自动尝试后续端口。

## 支持格式

### 图片

`jpg jpeg png webp gif avif bmp svg`

### 视频

`mp4 webm m4v mov mkv avi ogv mpeg mpg ts`

是否能直接播放取决于浏览器是否支持文件内部的视频 / 音频编码。Chrome / Edge 对 MP4(H.264/AAC)、WebM 等通常支持最好；某些 MKV、AVI 或特殊编码可能只能被识别但不能直接播放。

## 快捷键

- `/`：聚焦搜索框
- `E`：播放器内展开 / 收起整理面板
- `←`：查看上一个媒体
- `→`：查看下一个媒体
- `Esc`：关闭查看器

## 安全与隐私

LocalHub 默认只绑定本机回环地址 `127.0.0.1`。媒体文件通过本机 HTTP 服务直接提供给你自己的浏览器，不上传到互联网，也不需要账户或云服务。

整理操作会直接修改本地文件的名称和所在目录，但不会提供删除功能，也不会覆盖目标目录中的同名文件。Tag 则只写入 `.localhub/metadata.json`。

## 设计说明

视觉思路参考大型视频站常见的黑色背景、高密度缩略图和醒目强调色，但 LocalHub 是独立实现，不使用第三方品牌名称、Logo 或素材。

管理能力遵循一个原则：**浏览优先，整理按需出现**。普通状态保持视频网站式浏览；单文件管理停靠在播放器侧边；批量管理只有用户主动进入整理模式时才显示。
