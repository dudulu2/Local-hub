# LocalHub

一个完全本地运行的媒体浏览器，把普通文件夹变成类似视频网站的图片 / 视频媒体库。

## 特点

- 自动递归扫描当前目录及子目录中的视频和图片
- 深色高对比媒体网站式布局
- 视频 / 图片 / 收藏 / 继续观看分类
- 文件夹导航
- 文件名与目录搜索
- 名称、时间、文件大小排序
- 视频大窗播放、拖动进度、全屏、倍速等浏览器原生控制
- HTTP Range 分段读取，大视频无需一次性载入内存
- 图片大图查看
- 上一个 / 下一个与键盘方向键切换
- 收藏状态保存到浏览器本地存储
- 自动记忆视频播放位置并显示继续观看
- 响应式桌面 / 窄屏布局
- 不上传媒体，默认仅监听 `127.0.0.1`
- 后端只有 Python 标准库，无 pip 依赖

## Windows 最简单用法

1. 下载本仓库全部文件。
2. 把这些文件放进你要浏览的视频 / 图片总文件夹。
3. 双击 `打开媒体库.bat`。
4. 浏览器会自动打开 LocalHub。

项目会递归扫描同文件夹下的媒体，因此也支持：

```text
媒体库/
├─ 打开媒体库.bat
├─ server.py
├─ index.html
├─ styles.css
├─ app.js
├─ 视频/
│  ├─ A.mp4
│  └─ B.webm
└─ 图片/
   ├─ 1.jpg
   └─ 2.png
```

## 命令行运行

```bash
python server.py
```

指定其他媒体目录：

```bash
python server.py --root "D:\Videos"
```

不自动打开浏览器：

```bash
python server.py --no-open
```

默认地址通常为：

```text
http://127.0.0.1:8787/
```

若 8787 已占用，会自动尝试后续端口。

## 支持格式

### 图片

`jpg jpeg png webp gif avif bmp svg`

### 视频

`mp4 webm m4v mov mkv avi ogv mpeg mpg ts`

是否能直接播放取决于浏览器是否支持文件内部的视频 / 音频编码。Chrome / Edge 对 MP4(H.264/AAC)、WebM 等通常支持最好；某些 MKV、AVI 或特殊编码可能只能被识别但不能直接播放。

## 快捷键

- `/`：聚焦搜索框
- `←`：查看上一个媒体
- `→`：查看下一个媒体
- `Esc`：关闭查看器

## 隐私

LocalHub 默认只绑定本机回环地址 `127.0.0.1`。媒体文件通过本机 HTTP 服务直接提供给你自己的浏览器，不上传到互联网，也不需要账户、数据库或云服务。

## 设计说明

视觉思路参考大型视频站常见的黑色背景、高密度缩略图和醒目强调色，但 LocalHub 是独立实现，不使用第三方品牌名称、Logo 或素材，并针对本地媒体管理增加了文件夹、文件大小、继续观看、收藏和重新扫描等功能。
